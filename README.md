# 數碼暴龍02 雙人訓練師攻略

以讀者查閱需求重新編排的 Tag Tamers 繁體中文攻略。靜態 HTML/CSS/JavaScript，可直接部署 GitHub Pages，無需安裝或建置。

## 部署
將此ZIP內的 index.html、style.css、app.js、data.js、icon.svg、.nojekyll 及 assets 資料夾放在GitHub儲存庫的網站根目錄，然後在Settings → Pages選擇該分支及目錄。保留assets資料夾結構。亦可直接在瀏覽器開啟index.html查看。

## 內容
- 新手先讀：蛋種、裝甲、雙線冒險、7個FAQ。
- 合成與進化：原表69個蛋種、9期資料；有／無裝甲路線、EXP與JP、蛋群與合成素材篩選。
- 關卡攻略：32個關卡地圖條目，按主角與地區篩選，可放大，保留原圖。
- 數碼裝甲：14種裝甲及14種碎片。
- 道具列表：95項道具，按用途搜尋。
- 隱藏與資料：圖鑑獎勵、通關後要素、原作者引言及延伸資料。
